# FuelInvest V1 — Static Demo

واجهة V1 قابلة للنشر على GitHub Pages.

## تشغيلها

لا تحتاج Node.js. افتح `index.html` مباشرة، أو انشر المستودع عبر GitHub Pages.

## مهم

هذه نسخة واجهة تجريبية فقط:
- لا توجد قاعدة بيانات.
- لا توجد أموال حقيقية.
- لا يوجد دفع أو سحب حقيقي.
- تسجيل الدخول تجريبي.
- بيانات المشاريع والاستثمارات تجريبية.

المرحلة التالية تكون ربط Backend + PostgreSQL + KYC + مزود دفع مناسب + Ledger مالي، بعد مراجعة المتطلبات القانونية والتنظيمية.
